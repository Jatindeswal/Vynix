# Project Vynix: Paper-to-Code Mapping & Reproducibility Matrix (`PAPER_TO_CODE.md`)

This document provides a systematic audit comparing claims made in the Vynix paper draft against the verified repository codebase, checkpoints, and benchmark executions. Every factual statement is tagged with its source:
- `[MEASURED]`: Verified by executing commands or evaluator scripts and inspecting live output.
- `[LOG]`: Extracted directly from existing version-controlled configuration files, scripts, or commit history.
- `[UNKNOWN]`: Information not determinable from the repository alone and requiring author input.

## 2. Summary of Resolutions

1. **Protocol Alignment:** All benchmark figures in `FINAL_TABLES.md` now report official Box-Level Default setting mAP alongside legacy image-level AP.
2. **Single Source of Truth:**
   - `src/data/class_splits.py` provides the canonical 138 Rare / 462 Non-Rare HOI class splits and 80 COCO classes.
   - `src/data/predicates.py` defines the canonical 59 contact / 58 non-contact partition of the 117 HICO-DET verbs.
   - `src/config/hyperparameters.py` enforces frozen inference parameters from `review_response/frozen_hyperparameters.json`.
   - `src/models/checkpoint_loader.py` enforces parameter shapes and cache integrity.
   - `src/config/paths.py` eliminates all hardcoded local paths and drive letters.
3. **Safety & Non-Regression:** The regression test suite (`tests/test_regression.py`) guarantees 100% bit-exact prediction and mAP preservation.
